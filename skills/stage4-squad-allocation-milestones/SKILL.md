# Stage 4: Squad Allocation & Milestone Skill

This skill translates buffered engineering effort from Stage 3 into an optimal squad composition, calibrates calendar velocity using a strict **75% to 80% effective utilization factor**, and organizes execution into sequential **Milestones (M0 to M4)**.

---

## 1. Core Principles

1. **Balanced Squad Topology**:
   - Prevent top-heavy or junior-heavy antipatterns.
   - Maintain a core ratio of 1 Tech Lead : 1-2 Senior Devs : 1-2 Mid Devs : 0.5-1 QA : 0.5 Designer : 0.5 PM.
2. **The 75% to 80% Utilization Invariant**:
   - Never budget 40 hours/week of pure coding capacity per engineer.
   - Account for sprint planning, standups, retrospectives, code reviews, PR fixes, deployments, and PTO.
   - Effective capacity per dev = **30 to 32 productive engineering hours/week**.
3. **Milestone Governance (M0 to M4)**:
   - Each milestone delivers tangible working software with objective *Exit Criteria*.

---

## 2. Execution Runbook

1. **Ingest Handoffs 1, 2 & 3**: Review Scope, Architecture, and Buffered Effort Sprints.
2. **Dimension the Squad**: Calculate FTE allocations for Tech Lead, Devs, QA, Designer, and PM.
3. **Calculate Calendar Sprints**: Apply 75-80% utilization to total buffered dev-sprints to derive realistic project duration in weeks and months.
4. **Define Milestones M0 to M4**: Map macro-epics into chronological milestones with exit criteria:
   - M0: Inception & Architectural Setup (Weeks 1-3)
   - M1: Foundation & Core MVP (Weeks 4-7)
   - M2: Critical Integrations & Advanced Logic (Weeks 8-11)
   - M3: Hardening, Performance & Client UAT (Weeks 12-14)
   - M4: Production Cutover & Hypercare (Weeks 15-16)
5. **Chart Ramp-up / Ramp-down Profile**: Show FTE evolution across the project lifecycle.
6. **Emit Handoff 4**: Pass `Handoff 4: Delivery Plan` to Stage 5.
